# 🎮 Jogo Termo (Estilo Wordle)

Este projeto é uma versão web do popular jogo de adivinhação de palavras "Termo" (inspirado no Wordle). O usuário deve acertar uma palavra secreta de 5 letras em até 6 tentativas, com dicas visuais a cada tentativa.

## 📌 Funcionalidades

- Interface visual com grade de tentativas (6 linhas x 5 colunas)
- Teclado virtual para digitação
- Suporte ao teclado físico
- Cores indicativas para feedback:
  - 🟩 Verde: letra certa na posição certa
  - 🟨 Amarelo: letra certa na posição errada
  - ⬛ Vermelho: letra errada
- Botões de **Enter**, **Backspace** e **Reiniciar**
